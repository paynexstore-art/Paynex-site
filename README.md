# PayNex — Smart Installment Platform

التقسيط الذكي في مصر | Smart Installment Solutions

## 🎯 Overview

PayNex is an intelligent installment financing platform built with React + TypeScript + Vite. It provides users with seamless product browsing, order management, and installation tracking across Egypt.

## 🚀 Features

- **Product Catalog**: Browse 1000+ products across 8 categories
- **Installment Calculator**: Real-time monthly payment calculations
- **User Authentication**: Secure email-based login and registration
- **Order Management**: Track orders and installment plans
- **Admin Dashboard**: Comprehensive management system
- **Multi-language Support**: Arabic and English interface
- **Mobile Responsive**: Works on all devices

## 📋 Project Structure

```
src/
├── pages/          # All page components
├── components/     # Reusable UI components
├── contexts/       # React context providers
├── lib/            # Utility functions and business logic
├── constants/      # Application constants
├── types/          # TypeScript type definitions
└── assets/         # Images and static files
```

## 🔐 Security Policies

- **Authentication**: Email-only secure login
- **Data Protection**: LocalStorage encryption recommended for production
- **API Security**: Environment variables for sensitive config
- **Input Validation**: Strict validation on all forms
- **CORS**: Configured for trusted domains only
- **Content Security**: CSP headers enabled

## 📦 Installation

### Requirements

- Node.js 18+
- npm 9+

### Setup

```bash
git clone https://github.com/paynexstore-art/paynex-site.git
cd paynex-site
npm install
```

### Development Server

```bash
npm run dev
```

Opens at `http://localhost:5173`

### Production Build

```bash
npm run build
npm run preview
```

## 🧪 Testing

```bash
npm run lint
```

## 🌐 Deployment

### Vercel (Recommended)

1. Push code to GitHub
2. Connect repository to Vercel
3. Add environment variables in Vercel dashboard
4. Deploy automatically on push

### Other Platforms

Build and deploy the `dist/` folder generated by `npm run build`.
